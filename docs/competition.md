# 赛题摘要（532499）

官方入口：<https://tianchi.aliyun.com/competition/entrance/532499/information>  
规则来源：[CSIG 挑战赛公告](https://m.csig.org.cn/22/202607/53572.html)

## 赛事

- 名称：2026“Camera学术之星”影像算法技术竞赛 · 赛题一
- 主办：中国图像图形学会；合作：华为终端有限公司
- 对象：国内高校 / 科研院所在读学生
- 组队：最多 3 人，每人仅能加入一支队伍

## 任务

使用 **Diffusion / AIGC** 对挑战性元素做高质量、可控增强：

- 小人脸、文字、密集绿植、钟表、鸟类
- 更清晰，同时真实、自然、无伪影
- 内容一致、分辨率不变、色彩与结构协调
- 按与 Ground Truth 的接近程度计分

## 数据

| 集合 | 数量 | 说明 |
| --- | --- | --- |
| evaluation | 5 对 | LQ + GT，仅本地验证，不提交 |
| test（初赛） | 100 张 LQ | 五类场景，4K，GT 不公开 |
| test（决赛） | 20 张 | 现场发放并现场算分 |

## 提交

- 初赛：100 张 `jpg`，名称与测试图一一对应，例如 `case1.jpg`
- 目录：`output_dir/` 打成 zip
- 命名：`赛题一_作品名_队名_手机号.zip`
- 大小：zip ≤ 10GB
- 次数：初赛最多 10 次，每周 1 次
- 决赛：PPT + 现场 20 张结果
